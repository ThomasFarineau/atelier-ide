# File viewers

Built-in plugins open some files in a viewer, next to the source or instead of it.

## Markdown

For `.md` files, three modes at the top right of the editor, as in IntelliJ: editor only, editor and preview side by side (the default, with synchronized scrolling and a resizable split), preview only. The preview shows headings, lists, tables, colored code blocks, images relative to the file, links and ```` ```mermaid ```` diagrams; the boxes of task lists can be ticked from the preview. The modes are also in Search Everywhere (“Markdown: …”).

## Mermaid

`.mmd` files get an editor, the rendered diagram, or both side by side, with export to PNG and SVG. A big diagram is drawn in the background (shown in the status bar), so the window never freezes.

## SVG

A rendered preview next to the source or instead of it, as for Markdown.

## CSV

A table preview of delimiter-separated files (`.csv`, `.tsv`, `.psv`, `.tab`) next to the source or instead of it, with sortable columns.

## Images

PNG, JPEG, GIF, WebP, BMP and ICO files open in an image viewer instead of the text editor.

## Microsoft Office

Office documents open in a read-only viewer, with no office suite needed, the same on every OS, and export to PDF:

- Word (`.docx`): drawn as a page, with headings, character formatting, lists, links, tables and images;
- Excel (`.xlsx`): a grid with one tab per sheet;
- PowerPoint (`.pptx`): a column of slides.
