# Keyboard shortcuts

Atelier uses IntelliJ's shortcuts. On macOS, use Cmd for the Ctrl shortcuts of the editor.

## Files and navigation

| Shortcut | Action |
| --- | --- |
| Ctrl+O | Open a file |
| Alt+Insert | New document |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+F4 | Close the tab |
| Double Shift / Ctrl+P | Search Everywhere |
| Ctrl+Shift+N | Go to file |
| Ctrl+N | Go to symbol (classes, functions and types of the project) |
| Ctrl+Alt+S | Settings |
| Alt+1 | Project window |
| Alt+6 | Problems window |
| Alt+7 | AI Sessions window |
| Alt+F12 / Ctrl+` | Show or hide the terminal |

## Editing

| Shortcut | Action |
| --- | --- |
| Ctrl+W / Ctrl+Shift+W | Extend / shrink the selection (word, string, inside the brackets, brackets, line, file) |
| Ctrl+Shift+J | Join lines |
| Ctrl+Shift+U | Toggle case |
| Alt+Shift+Up / Down (or Ctrl+Shift) | Move the line or the selected lines |
| Ctrl+D / Ctrl+Y | Duplicate / delete the line (Ctrl+Y redoes right after an undo) |
| Ctrl+F / Ctrl+R | Find / replace in the file |
| Ctrl+Shift+F | Find in the project |
| F2 / Shift+F2 | Next / previous problem of the file (errors first) |
| Ctrl+- / Ctrl+= | Fold / unfold |

## Code intelligence

| Shortcut | Action |
| --- | --- |
| Ctrl+Space | Code completion |
| Alt+Enter | Quick actions (import…) |
| Ctrl+B / Ctrl+click | Go to declaration, or list the usages of a declaration |
| Ctrl+Shift+B / Ctrl+Alt+B | Go to the type declaration / implementations |
| Alt+F7 | Find usages |
| Ctrl+F12 | File structure |
| Ctrl+Alt+Left / Right | Back / forward |
| Ctrl+Shift+M | Matching bracket |
| Shift+F6 | Rename |
| Ctrl+Alt+L | Reformat code |
| Ctrl+Alt+Shift+L | Reformat file… |
| Ctrl+Alt+O | Optimize imports |

## Running

| Shortcut | Action |
| --- | --- |
| Shift+F10 / F5 | Run |
| Ctrl+F2 | Stop (Ctrl+C in the active terminal) |

## Git

| Shortcut | Action |
| --- | --- |
| Ctrl+K | Commit |
| Ctrl+Shift+K | Push |
| Ctrl+T | Update project (pull) |
| Alt+0 / Alt+9 | Commit / Git windows |
| F7 / Shift+F7 | Next / previous difference in the diff |
