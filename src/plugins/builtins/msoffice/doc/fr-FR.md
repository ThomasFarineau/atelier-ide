# Microsoft Office

Les documents Office s'ouvrent dans une visionneuse en lecture seule, sans suite bureautique, de la même façon sur tous les systèmes, avec export en PDF :

- Word (`.docx`) : dessiné comme une page, avec titres, mise en forme des caractères, listes, liens, tableaux et images ;
- Excel (`.xlsx`) : une grille avec un onglet par feuille ;
- PowerPoint (`.pptx`) : une colonne de diapositives.
