# Markdown

Pour les fichiers `.md`, trois modes en haut à droite de l'éditeur : éditeur seul, éditeur et aperçu côte à côte (par défaut, avec défilement synchronisé et séparation redimensionnable), aperçu seul. L'aperçu affiche titres, listes, tableaux, blocs de code colorés, images relatives au fichier, liens et diagrammes ```` ```mermaid ```` ; les cases des listes de tâches se cochent depuis l'aperçu. Les modes sont aussi dans Rechercher partout (« Markdown : … »).
