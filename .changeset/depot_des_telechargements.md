# Les téléchargements passent dans `atelier-ide-org/releases`

Atelier déménage dans l'organisation GitHub `atelier-ide-org`. Le lanceur cherche désormais les mises à jour dans le dépôt public [`atelier-ide-org/releases`](https://github.com/atelier-ide-org/releases), qui ne contient que les fichiers des releases. Il se met à jour de lui-même : rien à faire. La documentation est maintenant à l'adresse <https://atelier-ide-org.github.io/app/>.
